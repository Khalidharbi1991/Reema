## This round: checked, no finding

- **Timeout path:** `subprocess_runner` returns `TIMED_OUT` with the partial output. `version()` and `check_clean()` treat any non-zero code, `TIMED_OUT` included, as not ready (fail closed). `call` lists the workspace before the `finally` deletes it. A test covers a timed-out run that left a file behind.
- **Preflight caching:** the binary and config hash runs on every call. Any change re-runs the version and listings and is checked against the proof. A mismatch clears the cache. Caching the version for 10 minutes does not let a new binary through, because the binary hash changes first.
- **Proof record:** it now holds `install_fingerprint`. A failed proof still deletes an older pass. The fingerprint is taken again after the attempts.
- **Packages:** `requirements-worker.txt` pins exactly the two approved packages (`pyyaml==6.0.3`, `tzdata==2026.6`), each with one SHA-256, installed with `--require-hashes --only-binary=:all: --no-deps`. With hashes required, a pip config that points at another index cannot change what is installed. No package was added to REEMA or the web app.
- **Deploy order:** a test checks that the lock comes before robocopy and pip, and that only the contents are reset (`$Target\*`), not the target itself.
