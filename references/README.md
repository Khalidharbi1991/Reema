# Local Reference Material

This directory contains source documents used to generate or validate REEMA
outputs.

- `itom/` contains the ITOM PDF and DOCX knowledge sources.
- `access-management/` contains access-management policies and procedures.
- `process-documents/` contains process source documents, templates, and backups.
- `customer/` contains Customer guidelines and supplied SOP references.

PDF, DOCX, XLSX, and similar customer documents are intentionally ignored by
Git. Keep authoritative copies in approved organizational storage and do not
commit confidential material.
